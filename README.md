# etch-a-sketch

Introduction about the project 

The objective of the current project is the development of a browser
version of something between a sketchpad and an Etch-a-Sketch.

The idea is develop skills in DOM manipulation and Google search
to build an interactive application for the users.

Conclusion

This project has been develop with this tecnologies: HTML, CSS and
Javascript.

In this project, a grid was created, this grid will be used as a sketchpad
where the user can pass the mouse cursor to create a pixelated trail 
that follow it. This trail can have 3 colors (red, green and blue) with 10%
of opacity (the system choose the color for the area randomly).

This opacity makes the sketch look lighter and more beautiful.
